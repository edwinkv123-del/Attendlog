ATTENDLOG PWA FILES

Upload every file in this folder to the ROOT of your GitHub repository named attendlog. Do not upload student names or attendance data. Then enable GitHub Pages from Settings > Pages > Deploy from a branch > main > /(root).

The app stores its records in the browser storage on each device. Different phones have separate local data, but anyone using the same browser profile on a phone may be able to access that data. First open requires internet so the app can cache for offline use.
